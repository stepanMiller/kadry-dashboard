# Кадровый дашборд

Репозиторий для кадрового мониторинга ГКУ «ЦМК МО».

Текущее состояние дашборда актуализировано на 15.09.2026 по кадровому реестру `Для Миллера Реестр 15.09.26.xlsx`, подтверждённым управленческим уточнениям и отдельному действующему приказу по дистанционной/гибридной работе.

Основная страница: `index.html`.

Архитектура текущей версии:

- `index-base.html` — сохранённая кадровая база по реестру 21.08.2026;
- `index-08.html` — зафиксированная рабочая версия загрузчика на 08.09.2026;
- `index.html` — текущий загрузчик, который поверх состояния 08.09.2026 применяет изменения реестра 15.09.2026 и выполняет контрольные проверки;
- дистанционная и гибридная работа ведётся отдельно по приказу № 01-202/26 от 13.08.2026 и не перезаписывается отметками из кадрового Excel;
- вакансия главного аналитика на 0,5 ставки управленчески относится к блоку Чернышина; по реестру 15.09.2026 сама позиция отмечена как сокращаемая;
- сотрудники Поимцева Е.А. и Фомина О.В. дополнительно помечены проектной меткой `Центр ЖКХ`;
- Бурякова А.А. и Шершакова О.Г. сохраняются как физические сотрудники с нулевой ставкой, хотя в кадровом Excel их отдельные строки не выводятся.

Контрольное состояние на 15.09.2026:

- 137 физических сотрудников / 132 ставки;
- 8 вакансий / 7 ставок;
- всего 145 позиций / 139 ставок;
- сокращение: 17 сотрудников + 5 вакансий / 20 ставок;
- дистанционная работа — 4 сотрудника;
- гибридный график — 26 сотрудников.

Логика ЦСТ и других проектных меток остаётся сквозной: сотрудник сохраняется в численности своего заместителя и при необходимости одновременно отображается в проектном блоке без двойного учёта в общих итогах.
