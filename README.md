# Кадровый дашборд

Репозиторий для кадрового мониторинга ГКУ «ЦМК МО».

Текущее состояние дашборда актуализировано на 08.09.2026 по кадровому реестру `Для Миллера Реестр01.09.26.xlsx`, подтверждённым управленческим уточнениям и отдельному действующему приказу по дистанционной/гибридной работе.

Основная страница: `index.html`.

Архитектура текущей версии:

- `index-base.html` — сохранённая кадровая база по реестру 21.08.2026;
- `index.html` — текущий загрузчик, который применяет подтверждённые изменения после 21.08.2026 единым преобразованием и выполняет контрольные проверки численности и ставок;
- дистанционная и гибридная работа ведётся отдельно по приказу № 01-202/26 от 13.08.2026 и не перезаписывается устаревшими отметками из кадровых Excel;
- вакансия главного аналитика на 0,5 ставки управленчески относится к блоку Чернышина, несмотря на ошибочную привязку к Попову в исходном кадровом реестре;
- увольнение Тесленко И.Д. с 08.09.2026 применено: позиция ведущего специалиста в блоке Дивина / ЦСТ стала вакансией;
- устаревшие одноразовые GitHub Actions удалены; они не являются частью текущего процесса обновления дашборда.

Контрольное состояние на 08.09.2026:

- 136 физических сотрудников / 131 ставка;
- 9 вакансий / 8 ставок;
- всего 145 позиций / 139 ставок;
- дистанционная работа — 4 сотрудника;
- гибридный график — 26 сотрудников.

Логика ЦСТ остаётся сквозной: сотрудник сохраняется в численности своего заместителя и при необходимости одновременно отображается в проектном блоке ЦСТ без двойного учёта в общих итогах.
